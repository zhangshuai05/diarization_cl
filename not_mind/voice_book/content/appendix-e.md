# 附录 E 实验记录模板与指标词典

实验记录的目的不是写日志，而是让另一个人能从输入、配置、输出和版本复现你的结论。每次实验复制下面模板，删掉不适用字段，但不要删掉失败样例。

## E.1 实验记录模板

| 字段 | 内容 |
| --- | --- |
| 问题与假设 | 哪个现象需要解释，预期改变什么 |
| 输入 | 音频路径、采样率、通道、时长、许可 |
| 数据切分 | train/dev/test 规则，是否按说话人或会议隔离 |
| 配置 | 前端、模型、解码、线程、批大小、硬件 |
| 版本 | 代码提交、模型权重、依赖、驱动 |
| 指标 | 主指标、保护指标、P50/P95、区间 |
| 失败样例 | 时间范围、参考、输出、中间信号 |
| 结论 | 支持、否定或暂未证明 |
| 下一步 | 只改变一个主要变量 |

## E.2 常用指标的边界

- CER/WER：文本错误；依赖归一化、分词和对齐。
- DER：说话人分段错误；依赖 collar、overlap 和映射策略。
- FAR/FRR/EER：阈值任务的误报、漏报和平衡点；必须说明评测人群和阈值。
- SNR/ERLE：信号或回声诊断；不等于下游 ASR 质量。
- SI-SDR/STOI/PESQ：增强或感知质量的不同侧面；需确认适用范围和许可。
- RTF：平均计算速度；不等于首字或句尾延迟。
- P95 延迟：长尾等待；要写明起止时间点和热身策略。

## E.3 一页评测声明

每份报告至少写明音频切分、文本归一化、模型与权重版本、DER 的 collar 和 overlap 口径、硬件、并发数以及 P50/P95 的测量起点。指标变小但置信区间跨零时，结论写成“暂未证明改善”。

## 本章小结

- 好的实验记录让结论可以被复现、质疑和回滚。
- 指标名称相同不代表口径相同，边界必须随数字一起交付。
