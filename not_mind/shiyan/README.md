## 读结果：为什么"AEC 诊断数字 ≠ 识别质量"

**1. 同样的 SNR，完全不同的 ASR。** case_01/02/03 的输入 SNR 都是 10.0dB，ASR 却从"全对"一路崩到"大面积复读"。SNR 是能量比值，**不含时域结构**。回声延迟决定了它落在近端语音的什么位置：

- 50ms ≈ 音素级融合：人耳/模型都难分，基本无害
- 150ms ≈ 音节/字级错位：插出一个"您"（回声的字叠到下一个字上）
- 600ms ≈ 词/短语级复读：回声像"另一个人把话又说了一遍"——识别器把回音当真内容输出

**2. 数字更差的噪声反而没伤到 ASR。** case_07/08 输入 SNR 只有 8.8dB（比 case_01 还低），ASR 却全对。paraformer 这类神经模型对**加性噪声**很鲁棒，但对**结构化回声**（与语音同源的混叠）没有免疫。若只报 SNR，你会得到"8.8dB 的噪声格比 10dB 的回声格更干净"的荒谬结论——**SNR 排不了序，因为两格的错误机制根本不同**。

**3. VAD 段数也在悄悄变。** 回声/噪声把句间停顿的能量抬过了阈值，能量法 VAD 段数从 11 → 9/10：停顿被"填平"。这在真实链路里影响的是判停、端点、双讲逻辑——AEC 残余不一定被 ASR 报错，但会让 VAD 状态机行为漂移。

## 口径说明（诚实记录）

- 近端语音是 **SAPI TTS 合成**，非真人录音：无真实房间混响、口音、口误，频谱比真人干净，所有指标偏乐观。
- SNR 为全程口径（含句间停顿），不是语音段 SNR；回声不经过房间冲激响应（无多径），是理想"单径延迟+衰减"。
- 混音写盘前做了防削顶 clip（gain -3dB + 近端本身接近满幅时会先削顶再写 wav）。
- "VAD 段数"给两个口径：能量法（可解释、阈值可调）与 fsmn-vad（产品链路同款模型）。
- funasr 首次运行会在 modelscope 缓存下载模型（一次性，~1GB）；每格推理约 1s（本机有 GPU）。

# 可视化前端（fe/）—— 3A + VAD 处理链演示

打开 `fe/index.html`（双击即可，无需服务器/上网）。演示音频已内嵌，计算全部在浏览器里本地完成。

## 处理链与算法

```
近端说话人 x ─┐                   参考 = 远端 r（扬声器播放源）
远端 r(参考) ──┴→ 麦克风输入 y = x + g·r(延迟) + 噪声
   → AEC(NLMS)  → ANS(谱减)  → AGC  → VAD(能量法, 链尾)
```

| 模块 | 实现 | 可调参数 | 教学点 |
|---|---|---|---|
| 干扰合成 | 延迟+衰减副本、白/粉噪声 | 延迟/增益/噪声类型/SNR | 与 `aec_lab.py` 同口径 |
| AEC | 逐样本 NLMS 自适应 FIR | 滤波长度 L、步长 μ | L 必须 ≥ 回声延迟采样数；μ 大收敛快但残差大 |
| ANS | 谱减（STFT 512/128，逐 bin 中位数噪声谱，α=2.5，0.12 floor） | 降噪强度 | 强度大→干净但音乐噪声/语音损伤 |
| AGC | 目标 RMS 全局增益 + 限幅 | 目标电平 | 数字上的"响"不等于听得清 |
| VAD | 能量法（20ms/10ms/-30dB/250ms/120ms） | 阈值 | 与 `aec_lab.py` 完全同参数 |

界面：波形（所选阶段 + VAD 绿色底纹）、平均幅度谱、各阶段 SNR 对照、VAD 分段表、播放/下载 wav。

## 前端里值得动手看的现象

1. **双讲**（近端 x 与远端 r 同时说话——演示音频默认就是）：NLMS 把回声消掉的同时被 x 的能量带动，残差(excess MSE) 可能让 **SNR 不升反降** → 真实产品的 AEC 靠双讲检测(double-talk detector)冻结更新；这就是"AEC 诊断数字 ≠ 识别质量"的另一面。
2. **滤波长度 vs 延迟**：把回声延迟调到 ≥600ms 而 L 保持 2048(128ms) → AEC 完全失效（盖不到回声），波形和指标立刻暴露。
3. **μ 的权衡**：μ 大 → AEC 收敛快但稳态残差大；μ 小 → 底噪干净但短音频里看不出收敛。
4. **ANS 的边界**：噪声开 strong + 近端正常说话 → 听感"闷/音乐噪声"，频谱里高频被切平；这正是谱减的天生短板（非神经增强）。
5. **VAD 阈值漂移**：把 VAD 阈值从 -30 升到 -20 → 段数变多、短段碎；回声/噪声会把停顿"填平"导致段边界漂移。
