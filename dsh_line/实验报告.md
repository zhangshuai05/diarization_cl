# 说话人分离实验报告（第一轮）

日期：2026-08-28
数据：桌面 `C:\Users\EDY\Desktop\new\Audio`（双设备单胶囊麦克风，双人奶茶店点单对话，1m/1.5m/2m 三种距离，23 个文件带人工真值）→ 复制至本工作区，桌面原文件未改动。
> **数据事实订正（2026-08-28 晚，据 Claude 线工作日志）**：两副设备**分别佩戴在两个人身上**——116 戴顾客（zjl/ash）、118 戴店员（wzy）；"距离"= 两人对话时的**相互距离**，不是麦到人的距离；录音环境为嘈杂游戏厅（另有安静环境对照）。因此单通道物理规律是"**保近弃远**"：每个麦只清自己的佩戴者，远处那人分离不出来。本报告后续所有"2m 不可分"的结论均在该前提下成立，且已被 Claude 线的双设备软融合验证（2m 两路互补合并后 21 句完整双人对话，救回远处顾客）。
环境：系统 Python 3.12.10 + torch 2.11.0+cu128（RTX 5060 8GB）+ funasr 1.3.14；模型全部走本地缓存（SEACO 953M / FSMN-VAD / CAM++ / CT-punc / SenseVoiceSmall），全程离线。

## 一、流水线

```
WAV(16k 单声道)
 → FSMN-VAD 切段
 → 每段 1.5s/0.75s 滑窗切块 → CAM++ 192 维声纹嵌入
 → 谱聚类（特征间隙自动定人数，1~15）+ 簇中心余弦 ≥0.78 迭代合并（funasr 内置 ClusterBackend）
 → SEACO Paraformer ASR + CT-punc 标点 → 分句 → 按时间最大重叠分配 spk 标签
 → 输出 sentence_info: [{start, end, spk, text}]
```

评估方法：真值 23 文件逐轮文本与系统分句文本做相似度对齐（阈值 0.35），统计每个真人映射到哪些 spk 标签、主标签纯度（同人句子落在其主标签的比例）、文件级标签数。

## 二、关键发现（按重要性排序）

1. **funasr 1.3.14 的 SEACO 单独跑不输出说话人标签**——必须外挂 `spk_model="iic/speech_campplus_sv_zh-cn_16k-common"` 才会在 `sentence_info` 里生成 spk（源码确认：`auto_model.py` L248-275, L809-884）。上一轮桌面会话的 SEACO 结果因此丢掉了全部说话人信息。

2. **"同一人第二次说话变成 speaker_N" 真实发生**。auto 模式 23 文件中，最差案例 `Call20260718211938.wav`（116@2m）拆出 8 个标签。拆标签与并标签两种失败同时存在，且与距离强相关。

3. **2m 距离的头号杀手是 VAD，不是聚类**。噪底被麦克风 AGC 抬到满幅后，FSMN-VAD 把整段录音判为"连续语音"（116@2m 只有 1 个 VAD 段，44.5 秒语音全程不断句）——VAD 不切段，后续一切无从谈起。

4. **挖出 funasr VAD 的一个隐藏坑（本次最大技术收获）**：funasr 1.3.14 的 VAD 默认开启"动态静音调度"（`dynamic_silence`），在说话期间会把 `speech_noise_thres` 硬重置为 0.5（`fsmn_vad_streaming/model.py` L964）。对 2m 满幅噪底录音，这导致噪底永不触发断句。**关闭后（`vad_kwargs={"dynamic_silence": False}`，阈值 0.7）**：116@2m 分段数 1→16，118@2m 4→8~11，接近真值轮数（15 轮/44.5s）。同时该参数不能通过运行时 kwargs 传（`init_cache` 只认 config.yaml），需修改本地模型配置。

5. **降噪路线的现实问题**：谱减法对 2m 数据无效（SNR 只有几分贝，"减噪底"等于"灭信号"，输出峰值 1→0）；FRCRN 在本机没有可用实现（系统 funasr 缺 `modelscope.models.decoder` 模块导致 FRCRN 未注册；modelscope 1.38 缺 FRCRN pipeline 代码；3d-speaker 环境的 modelscope 1.18 能跑但纯 CPU RTF≈31 倍，不可接受）。FRCRN 的 README 还明确警告"多说话人干扰场景性能下降"——降噪不是 2m 问题的正确答案，修 VAD 才是。

6. **自定义聚类实验**（自写 AHC 阈值扫描 / 谱聚类 / 特征间隙 / 0.78 合并，共 12 策略 × 4 文件）：AHC 平均连接 + 距离阈值在 1.5s 块嵌入上全面碎片化（阈值 0.5 都能切出 154 簇）——该路线排除；自写谱聚类不优于 funasr 内置。**说明瓶颈在嵌入质量，不在聚类算法**。

7. **preset_spk_num=2 是双刃剑**：能救回部分 auto 炸裂的文件（116@2m），但 k-means 在退化数据上会把所有人并进一个簇（118@1m、116@1m 都出现过"两真人同标签"）。预置人数只适合"明确知道几个人"的场景，且不保证正确。

8. **设备差异显著**：同价位同规格，Device118 整体明显优于 Device116（118 的 1.5m 全部正确检出 2 人；116 的 2m 最差）。买 40 元麦有抽奖成分。

9. **ASR 文本质量**：SEACO 文本明显劣于 SenseVoiceSmall（如"甜度冰度"识别成"盐入十分钟"）；SenseVoiceSmall 文本干净但带 rich 标签（需剥 `<|zh|><|HAPPY|>` 等）、噪声段会幻觉英文/日文，且无字级时间戳导致分离回退到 vad_segment 模式、标签更碎。**文本与分离结构需要换模型组合**。

## 四、结论

1. **1m 距离可用**：店员纯度≈1.0，顾客 0.6~0.9；2m 在修复 VAD 前完全不可用，修复后 116@2m 恢复可用（zjl 0.86），118@2m 仍失败。
2. **单胶囊 40 元麦克风的物理上限已经摸到**：2m 距离 + 1.5s 短块，CAM++ 嵌入的说话人可分性不足，任何聚类都救不了。要么靠近麦（≤1m），要么换多胶囊/更好的麦。
3. **流程层面的最优组合**：VAD 修复（dynamic_silence=False + thres 0.7）+ funasr 内置谱聚类 auto + SEACO 分离结构；ASR 文本应换 SenseVoiceSmall（下一步）。
4. 对"张三变 speaker_6"的回答：**它真实存在，根因是嵌入质量随距离/噪声漂移 + 自动定人数不稳**；可用"限制说话人数 + 会话内语义线索"缓解，但单通道便宜麦下没有银弹。

## 七、第二轮：嵌入诊断与分离优化（同日续，不换 ASR、不做 LLM）

**1. 嵌入诊断（根因定位）**：用最优分离结果给块打伪标签，统计类内/类间余弦相似度：

| 文件 | 块级类内/类间 | 段级聚合后类内/类间 |
|---|---|---|
| 116@1m | 0.285 / 0.224 | 0.538 / 0.400 |
| 116@2m | 0.289 / 0.266 | 0.404 / 0.427 |
| 118@1m | 0.283 / 0.278 | 0.545 / 0.447 |
| 118@2m | （仅 1 个伪标签，无法统计） | 0.716（单人） |

结论：**1.5s 块级嵌入几乎没有类可分性**（类内≈类间）；段级聚合（段内平均）后 116@1m/118@1m 出现真实但有限的差距（0.54 vs 0.40~0.45）。这正是"任何聚类都调不动"的根因——**瓶颈在嵌入质量，不在聚类算法**。

**2. 修复了自己的 AHC bug**：初版把完整相似度方阵直接传给 `scipy linkage`，被当作"观测向量"做了欧氏聚类——之前"AHc 碎片化、排除 AHC 路线"的结论全部作废。修正为 `squareform` 压缩距离矩阵后，**AHC（距离阈值 0.50~0.70）成为最强策略族**。

**3. 系统性实验**（23 文件 × 24+ 策略：块级/段级 × AHC 距离阈值扫描 / 谱聚类 k2 / 特征间隙 / 0.78 合并 / 白化 z-score / 1.5s 与 3s 块）：
- 天花板分析（每文件事后挑最优策略）：**0/23 个文件能达到"2 标签 + 两人主标签不同 + 双方纯度 ≥0.8"**。
- 最好成绩：116@1m `seg_ahc_d0.70` 两人纯度 0.857/0.846，但主标签相同（合并失败）；真正分离的案例最好约 0.57~0.77（较弱说话人）。
- 白化与 3s 长块均无突破。

**4. 118@2m 死案定论**：该录音的 ASR 输出 14 句全是店员，顾客台词一句未识别——**信号里没有第二个人的可转写语音**，分离算法无米下锅。2m 场景下每台设备都只能"捞到"一个说话人（116 只捞到顾客、118 只捞到店员）。**原因已查明（设备佩戴事实，见文首订正）**：顾客距店员佩戴的 118 麦有 2m 之远——不是聚类/降噪问题，是单通道物理规律"保近弃远"。该场景的正确解是双设备融合（Claude 线），单路分离无解。

**5. 最终结论**：
- 本麦克风 + 本距离条件下，**自动说话人分离的物理上限已经摸到**：1m 可用（店员≈1.0、顾客 0.6~0.9），2m 不可行。
- 系统级最优配置：**VAD 修复（dynamic_silence=False + thres 0.7）+ funasr 内置谱聚类 auto**（无需自定义提取，结构最稳）；自定义段级 AHC（d0.55~0.65）为可调备选。
- 想真正突破上限，方向只剩三个：① 会议开始时每人自报姓名做**现场声纹注册**（注册段长且干净，远稳于 1.5s 块，可直接解决"顾客被吞"）；② 换多胶囊麦克风；③ 接受标签瑕疵用语义/人工后修正。

## 九、第三轮：在线统计分离（"边放边注册"，不提前注册）

**思路**：按时间顺序流式处理，维护每个说话人的累积质心（声纹统计）；新段与质心比：像→并入并 EMA 更新；中间态→只分配不更新（防污染）；不像→新建（冷启动）。可选：低阈值在线建池 → 质心余弦合并 → 离线精修。实现：`online_diar.py`。

**原理优势（与批式聚类的本质区别）**：批式是"块 vs 块"（噪声对噪声）；在线是"块 vs 累积质心"（噪声对统计），且**优势随会议时长增长**——质心方差随每人累计语音量下降。

**结果**（4 文件，阈值组合扫描 + 合并 + 精修）：
- 成绩与批式天花板持平：好案例 wzy 0.93 / zjl 0.86，但主标签相同（顾客仍被吸进店员链）；0/4 干净分离。
- **机制验证**：分配时"本段 vs 己方质心"相似度随会议推进单调上升（116@1m：0.547→0.723；118@1m：0.623→0.735），"己方-他人"间隔在 118@1m 从 0.33 升到 0.50——质心确实在变准，边放边注册的假设成立。
- 局限：测试录音每人仅 1~2 分钟语音（约 15 段），质心远未"成熟"；真实会议 30~60 分钟时该方案的优势才能完全体现——**需要长录音验证**，现有数据测不出它的上限。
- 天花板仍在嵌入可分性：难文件（116@1m）中段间隔掉到 0.09，两个声纹太近时吸收风险无法根除。

**结论**：在线统计是最终"边录边处理"系统的正确架构形态（与多设备融合互补：多设备提供新信息，在线质心提供时间累积）；建议下一步用 5~10 分钟真实会议录音验证长时优势。

## 十、第四轮：在线增量分离深研 + GitHub 开源调研

**GitHub 调研**（有限调研，未直接搬代码）：
- [UIS-RNN](https://github.com/google/uis-rnn)（Google，已归档）：在线增量分离的学术原型——每说话人一个可学习 GRU 状态 + CRP 新说话人先验 + 高斯发射。核心能力来自**监督训练**的 GRU，而非先验结构。
- [diart](https://github.com/juanmc2005/diart)（pyannote 系在线框架）与 [StreamingSpeakerDiarization](https://github.com/ishine/StreamingSpeakerDiarization)：依赖 pyannote 模型链，本机离线装不了，仅作算法参考。

**实现与实验**（`bayes.py` / `online_diar_v2.py` / 合成长会议 `build_long_meeting.py`）：
1. 合成长会议：同人同设备文件拼接（L1 348s/102 轮、L2 270s/89 轮、L3 265s/64 轮），跨距离拼接顺便模拟"人边说话边走动"。
2. v2（z-score 归属 + 鲁棒聚合）：长会议碎片化严重（7~24 标签），z-score 启发式失败。
3. vMF 贝叶斯版（对角高斯→球面高斯）：踩到两个数值/结构坑——
   a) n=1 经验方差退化（方差=偏差²）使高斯似然与距离无关；
   b) 每说话人独立 κ 时，vMF 归一化项 logC(κ) 差几百量级，比较被归一化项淹没；
   c) 修掉 a/b 后，小 κ 区间归一化恒定，模型退化为 κ·cos+先验，而"新说话人分支"用全局均值做模板——全局均值被第一个说话人主导，**新说话人分支在结构上永远输给既有说话人**。
4. **理论收敛结论**："新说话人分支"等价于常数阈值——v1 的硬阈值就是贝叶斯创建代价的变形。UIS-RNN 的价值在训练出来的 GRU，不在 CRP。无监督条件下，阈值式在线分配 + 鲁棒聚合就是正确形态。

**长会议最终结果**（v1 阈值式）：L1 匹配 100/102 轮（文本对齐质量大幅好于短文件），但 **distinct=False 依旧**——句子级 2 标签、两人主标签都是 0（吸收）。L2/L3 同。

**最终结论（在线方向）**：
- 质心随累积变准的机制验证通过（第四轮前已验证），但**会议变长没有解锁分离**——吸收错误在长会议中依旧，因为瓶颈是"两人嵌入分布重叠"（类间 0.40~0.45 vs 类内 0.54），任何无监督决策规则（阈值/贝叶斯/z-score）共享同一信息，都到同一上限。
- 文献给出的破局点一致指向**监督学习**：用带标签数据训练说话人模型（UIS-RNN 的 GRU 或 判别式嵌入微调）。本数据集 23 文件有轮级标签，可用现有分离结果生成伪时间戳构造训练序列——这是本方向唯一有实质提升空间的下一步。
- 硬件侧破局：多设备融合（Claude 线）——增加新信息，而非重排已有信息。

## 十一、第五轮：监督 UIS-RNN 留出集评估 vs 基线 + 验收判定

**方法**：用 23 个带轮级标注录音的"伪时间戳 → 段级嵌入序列"训练一个 UIS-RNN 监督在线分离模型（每说话人一个权重共享 GRU 状态 + 高斯发射 + CRP 新说话人先验），推理端用在线贪心分配替换 v1 的硬阈值聚类。18 文件训练 / 5 文件留出（`Call20260718210454`、`Call20260718211745`、`Note20260803111436`、`Note20260803112655`、`Call20260718211938`，从未参与训练）。评估沿用既有口径：真值轮文本与系统分句文本相似度对齐（阈值 0.35），统计每人主标签纯度、文件标签数、`distinct`（两人主标签不同）与 `good`（distinct 且 n_spks≤2 且双方纯度≥0.8）。

**下一步**：(1) 用 best-ckpt / 早停重训（末态换 epoch110）；(2) 调 `transition_bias=2.0` 或减小 `crp_alpha` 抑制新说话人分支；(3) 数据侧扩量（长录音 / 更多文件）——18 文件 ~200 有效段的监督信号不足以让 GRU 学会超越嵌入可分性上限；本数据下监督路线的实质提升空间有限，瓶颈仍在单胶囊麦的嵌入质量（见第七/十节）。

**模型层面的已知缺陷**：新说话人分支的发射先验硬编码为 0，而既有说话人携带高斯归一化常数（192 维下约 ±54 nat），"新建 vs 并入"的决策被这一任意常数主导（σ=0.3 的选择本质是翻转该常数符号）；报告中提出的 transition_bias/crp_alpha 调参杠杆在该缺陷下尺度错位，后续改进应首先为新说话人分支引入一致的发射先验（如全局嵌入分布），再谈调参。

## 十二、第六轮：修复新说话人发射先验缺陷 + 重训重评

**改动**（`sup/uisrnn.py`、`sup/train.py`，`sup/` 全部 14 测试保持通过）：

1. 新说话人分支发射项由硬编码 `0.0` 改为可学习全局高斯先验 `N(e; prior_mean, exp(prior_logvar)·I)`：`prior_mean` 为 192 维向量、`prior_logvar` 为标量，初始化为 `log(σ²)=log(0.3²)=log(0.09)`，使新说话人分支与既有说话人携带同一高斯归一化常数、处于同一尺度。新增方法 `_prior_emission_logp(e)`（`sup/uisrnn.py:49-54`），`_step_logp` 中新说话人候选改为 `emit_new = self._prior_emission_logp(e)`、`trans_new = log(crp_alpha)`（`sup/uisrnn.py:72-74`）。两参数只走 `state_dict`，未加入 ckpt 的 `args` 字典（`sup/uisrnn.py:38-41`）。
2. `train.py`：每 epoch 的 NLL 改为按帧平均（`frame_nll = Σloss / Σmask.sum()`，`sup/train.py:57,62`），维护 `best_frame_nll`/`best_state`（`deepcopy`，`sup/train.py:46-48,63-66`），训练结束保存 best 状态到 `output/sup/ckpt/model.pt`（`sup/train.py:69-76`）。
