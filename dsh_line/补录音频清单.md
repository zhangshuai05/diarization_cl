# 补录音频清单（给方向 A 监督训练用）

> 目的：监督路线的硬顶是数据（现 23 个短文件、伪标签覆盖约 50%）。补录重点是 **1m 双人可闻场景**——这是融合架构下分离引擎真正的战场（2m 已由双设备融合解决）。

## 录什么

| 项目 | 要求 |
|---|---|
| 场景 | 1m 距离双人对话（各自佩戴原设备 116/118，保持与现有数据同构） |
| 时长 | 每段 ≥ 3 分钟；**3~5 段**，最好跨不同环境（嘈杂/安静各半） |
| 内容 | 自由对话或照旧剧本均可；**不要刻意轮流**，自然插话更好（覆盖短应答） |
| 说话人 | 尽量沿用 zjl / ash / wzy 原班人马（跨文件声纹一致性有助于长会议拼接实验） |
| 形式 | 与现有文件相同：16kHz 单声道 wav（aac 原始件也保留） |

## 同步要做的标注（关键，决定数据价值）

- 打开 `Transcribe.xlsx` 风格的真值表，**逐轮**标 `speaker: 文本`（可事后听着录屏标）；
- 额外记一列**环境**（嘈杂/安静）与**距离**（必须为 1m）；
- 标注时保留自然的口语原样（嗯、啊、重复词），不要"润色"——ASR 对齐需要字面一致性。

## 录完放哪

丢进本工作区 `Audio\` 下新目录（如 `Audio\Session2\Device116\...`），并在 `Transcribe.xlsx` 或单独 json 里补真值；告诉我文件名规则即可，我来接评估管线。

## 为什么这样录

1. 1m 双人可闻 = 单路分离唯一有信息量的场景（2m 单路无解、融合已覆盖）；
2. ≥3 分钟 = 每说话人累计语音量上去了，段级嵌入与质心统计都更稳（之前诊断：质心随累积变准，短音频是最不利场景）；
3. 嘈杂/安静各半 = 让模型学会区分"环境噪声导致的嵌入漂移"和"说话人差异"。
