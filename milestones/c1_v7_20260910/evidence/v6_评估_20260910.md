# c1 v6 分离评估

评估使用 DSH `eval_der.py`，0.1 秒帧，GT 说话人至系统标签多数映射，`collar=0.5s + trim`。
本轮只评估时间段和说话人标签；ASR 文本没有参与算法或结论。

## 变更

v6 在 v5 的短窗细化路径上增加一步**低置信碎段吸收**（`_absorb_slivers`）：
0.6s/0.15s 密集窗逐窗边距判决本身是零门槛（`margin >= 0`），
在近单说话人段内会出现边距极小的短 run，被切成 0.15~0.6 秒的假碎段。
新规则只吸收「时长 < 0.75s **且** 边距绝对值均值 < 0.18」的 run，并入边距更高的邻居；
两个阈值都可调，真短答（本批 0.9~2.6 秒、边距 0.19~0.41）不受影响。
