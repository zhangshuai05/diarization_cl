## R1. 指标（**修正旧版 §1.1 的评价漏洞**）

旧版写"只报**有覆盖**的句子"——这与"弃权计入正确率分母"**直接冲突**，
会重新奖励"少输出"的系统（本项目已真实踩过：k=2 碎簇只剩 1 窗时，
只答 1 句且答对会报 100%）。**冻结规格不能成为保留已知错误的理由。**

| 项 | 冻结值 |
|---|---|
| **总体正确率** | **包含全部参考标注句**。无覆盖 = **未答对**，留在分母里 |
| 弃权率 | **另报**（不混入正确率） |
| 未匹配率 | **另报**（有预测但标签未被匈牙利映射；与弃权是两个量） |
| 主指标 | 按句平均（`per_sentence`） |
| 辅指标 | 时长加权（`duration_weighted`），两者都出现 |
| 句子单位 | 单 tier 非空 mark |
| 标签置换 | 匈牙利 |
| 分栏 | `overlap` / `clean` 保留；短句留在总体、另列 `short` |

## R2. B 的图构造与索引（**修正旧版 §1.4 的数学错误**）

旧版冻结 `W = (1 + cos) / 2`。**错**：它把正交对（cos=0）映射成 **0.5**，
于是"互相正交的 k 个团"之间仍有强连接，**图不是块对角**。
实测该构造下理想块数据的谱为 `0, k/(k+1), …, k/(k+1), 1, …`，
最大间隙**恒在第 0 位**、与真实 k 无关。

| 项 | 修订值 |
|---|---|
| 相似度图 | **`W = max(cos, 0)`**（非负截断，保留"正交 = 无连接"） |
| 归一化拉普拉斯 | `L_sym = I - D^{-1/2} W D^{-1/2}` |
| 间隙定义 | `gaps[i] = λ_{i+1} - λ_i`，零起始 |
| **K** | **`argmax(gaps) + 1`**（标准零起始；**不是 `+2`**） |
| 是否跳过首间隙 | **不跳过**——跳过会排除合法的 **K=1**，是绕症状 |
| 相对间隙 / 随机图零模型 | **本轮不引入**（避免零分母，且明显扩大范围） |

**验证**：`max(cos,0)` + `+1` 在正交块数据上恢复 **K=1/2/3/4/5**（逐例通过），
含抖动情形；全同向量给 **K=1**（旧版给 2）。

## R5. 可复用的中间结果（**修正旧版 §2 的说法**）

旧版说"复用细化产物"——**不准确**。可跨 K 复用的是**符合相应路径要求的嵌入等中间结果**，
**不是一份最终标签**：

| 可复用 | 不可复用 |
|---|---|
| 模型（进程内跨场复用，现有脚本已在会议循环外加载） | 最终细化标签 |
| VAD 区间 | —— |
| 主窗嵌入（2.0s/1.0s） | 密窗嵌入（0.6s/0.15s，仅细化/救援需要） |
| AHC 树（同嵌入下所有阈值共用） | —— |

**细化结果必须按候选 K 区分**：k 不同 → 锚点不同 → 细化输出不同。

## R6. 分批实测成本（**替换旧版 §1.5 的估算**）

旧版的 45 分钟是**猜的**，且"一场耗时 × 12"是错的。分三段测：

| 段 | 测什么 |
|---|---|
| C1 | **模型首次加载**（CAM++ / FSMN 各一次） |
| C2 | **单场 VAD + 主窗 + 密窗特征提取** |
| C3 | **缓存就绪后，一个不同 K 的细化与评分** |

然后按各场**去重后的候选 K 数量**估算总预算。
**超预算就停下报告，不自行放宽。**
