## 0. 本轮回答什么

两个**简单**候选判据，在**同一条真实路径**上比较：

- **A — AHC 距离阈值切树**：在聚类树高度上切一刀。阈值**只在 dev 上选**。
- **B — 归一化谱间隙**：由相似度图的谱结构产生 K 候选，**本轮只估计 K**。

**不作**：不设计综合打分函数；不给任一候选预设优胜。

## 1. 冻结项

### 1.1 指标（主 / 辅）

| 项 | 冻结值 |
|---|---|
| 主指标 | **句子级说话人归属率**，**按句平均**（`per_sentence`） |
| 辅指标 | 时长加权（`duration_weighted`） |
| 报告口径 | 只报**有覆盖**的句子；弃权率与未匹配率单列（两者不混） |
| 句子单位 | 单 tier 非空 mark |
| 标签置换 | 匈牙利（`scipy.optimize.linear_sum_assignment`） |
| 重叠分栏 | 保留 `overlap` / `clean` 两栏 |
| 短句 | 留在总体，另列 `short` |

> 主指标从**时长加权改为按句平均**：本轮目标是"每句话尽量归对人"，
> 与项目负责人口径一致。**辅助报时长加权**，两者都出现。

## 2. 去重复用真实路径结果（成本控制的关键）

真实路径的每场**只跑一次**，把下列中间产物存到一个新产物文件里，A/B 共用：

```
artifacts/v13_ab_dev_pathcache.json
  per meeting:
    windows: {times, n}          # 主窗几何（不存嵌入，太大）
    base_k: 选 K 现状（objective+min_win=2）
    refined: {labels, times}     # 细化后的最终标签（A/B 共用）
    der_base / attribution_base  # 现状基线
```

**为什么可行**：A 与 B 只改"选 K"这一步，**细化输入是主窗嵌入**（A/B 相同）。
所以细化结果**可以复用**——只要 A/B 选出的 k 相同，细化产物完全相同；
k 不同时，细化必须重跑（这是唯一无法省的部分）。

**因此实际成本** = 1 次基线全跑 + 「A/B 选出的 k 与基线不同」的场次 × 细化成本。
