## BUGGY 那份为什么失效

生成它的评价器有三个 bug，**每个都会改变排名**（不只是数值）：

1. **整数 0 簇被整个丢弃。** `segment_map` / `frame_map` 用 `if nm` 判空，
   而整数 `0` 在 Python 里是 falsy。后果：
   - `k=1` 时 `clusters_for` 返回全 0 → 全部丢掉 → **k=1 恒报 0.0% 全弃权**；
   - `k≥2` 时丢掉 0 号簇（**按首次出现顺序编号，不天然等于最大簇**）
     → k=3 的值大量落在 12–46% 的**假低谷**。
2. **弃权句被移出正确率分母。** 导致"只答 1 句且答对"报 **100%**
   （真实触发：`L_R003S01C02` 的 k=2，簇 `[417, 1]`，102 句里 101 句无覆盖）。
3. **短句被 `min_sentence` 从总体剔除**（99 句 vs 102 句），
   与项目负责人"短句必须留在总体、另列一栏"的要求相反。

三项修复后，旧 sweep 与新 sweep **48 个格子里 47 个不同**（只有 1 格逐位相同）。
逐格对比见 `scripts/evaluation/_diag_old_vs_new_sweep.py`。

**注意归因限度**：上述三项是**同时**改的，**没有做逐项消融**。
所以只能说"修正评价器后，三个对照的改善均值比从旧结果变为约 1.067"，
**不能**断言其中多少由标签 0 单独贡献。

## 因此作废的结论（不要再引用）

| 已撤回的结论 | 撤回原因 |
|---|---|
| 「代理 Δ 与真实 Δ 相关 r=+0.893」 | 污染尺子上的数。修正后 Spearman rho=+1.000（**描述统计正确**） |
| 「p=0.000 显著」 | **不能作为显著性证据**：n=3 且无并列时，枚举全部 6 种排列，双侧精确置换检验 **p=2/6≈0.333**。SciPy 的默认近似 p 值在此不适用 |
| 「放大系数 1.5 倍」 | 修正后为 **1.067 倍**（40.76÷38.20）。但多因素同时变更，**不能**全部归因于标签 0 |
| 「k=1 的 0.0% 是尺度下限」 | 是标签 0 被过滤的产物，不是尺度下限 |
| 「代理缺碎簇惩罚」 | 旧结论建立在污染数据上；`sentence_k_rule.FRAGMENT_PENALTY` **未标定** |
| 「修复后 2/12、3/12 与旧结果逐位相同」 | 那次对比的两侧走**同一段有 bug 的代码**，不构成独立证据 |
| 「代理选 k 只有 2/12 一致」 | **口径混称**：那是"各自全集"口径。受限于旧版只测 1,3,5,7，"共同网格"口径是 **11/12**。两个数必须分开报 |

## ⚠️ 当前分数是**监督评价分数**，不能直接用于部署选 K

这一条**不是**"更多配对实验后可能成立"的问题，而是定义上的：

> **读取目标会议真值的分数，本身就不能用于未知会议的推理。**

句子级归属率需要知道"每句是谁说的"（真值锚）才能算。所以它**天然是评价指标**，
不是可部署的判据。

配对实验只能回答一个**不同**的问题：**粗窗代理分数是否近似最终路径的效果**。
可部署的 K 规则必须**另行设计**，不能读目标会议真值。

## 仍未验证的事（不要当成结论）

- 修正后的代理**能否**预测真实路径的增益：n=3（且这三场是**经过选择**的
  ——只有真实路径换了 k 的场次才进对照），只能说方向与排序一致。
- 改善均值比 ≈1.067 是否稳定：只在 3 个场上观察到，多因素同时变更，
  **不能**归因于单一修复，也不能外推。
- 它是否可作部署用的 K 判据：**未验，且按上面的定义它不可直接部署**；
  需要另行设计不读真值的规则，并用最终路径的句子归属率评价。
